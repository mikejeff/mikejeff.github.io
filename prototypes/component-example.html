Component Example

The Component Example component is a simple documentation pattern for showing a UI element in two states: rendered and inspectable.

It presents a live preview of a component in use, followed by the exact markup used to create it. In this example, it demonstrates the same button treatment applied to both a native <button> element and a styled anchor, making it useful for showing how a component behaves across different semantic contexts.

The component is split into two sections:

  • Preview: renders the component as it appears in the interface so its visual treatment and behavior can be evaluated in context.
  • Source: displays the corresponding HTML in a readable code block so the implementation can be referenced directly.

Structurally, it acts as a lightweight pattern documentation block. It's part demo, part code reference. It is useful for documenting reusable UI components, comparing semantic variations, and building a component library in public without needing separate design artifacts.
